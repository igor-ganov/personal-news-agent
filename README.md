# Ветка `dist` — готовый APK

Здесь лежит собранный и подписанный APK, и больше ничего. Ветка сиротская:
у неё нет общей истории с кодом, и она переписывается целиком при каждой
выкладке, чтобы старые сборки не копились в репозитории.

| Файл | Что это |
| --- | --- |
| `personal-news-agent.apk` | подписанный APK, arm64-v8a, minSdk 24 |
| `VERSION` | тег релиза, который получит эта сборка |
| `SOURCE_COMMIT` | коммит кода, из которого она собрана |

Скачать напрямую:

```
https://github.com/igor-ganov/personal-news-agent/raw/dist/personal-news-agent.apk
```

Пуш в эту ветку запускает `publish-apk.yml`, который кладёт APK в релиз с тегом
из `VERSION`. Секретов workflow не требует: подпись ставится до попадания сюда,
а релиз создаётся встроенным `GITHUB_TOKEN`.

Ключа подписи здесь нет и не будет — репозиторий публичный, и ключ в нём означал
бы, что кто угодно может подписать APK, который Android примет как обновление
установленного приложения.
